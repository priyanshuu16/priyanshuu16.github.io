# priyanshuu16.github.io

Personal portfolio of **Priyanshu Raj**, a full-stack engineer (C# / ASP.NET Core, Angular, React, ML).

Live at **https://priyanshuu16.github.io**

- One self-contained `index.html`, with no build step and no frameworks
- A hand-written WebGL orb (simplex-noise displaced icosphere)
- Scramble-decode name, scroll-reactive marquee tapes, magnetic buttons and a custom cursor
- Responsive; respects `prefers-reduced-motion`

To edit, change `index.html` and commit. GitHub Pages redeploys automatically.
