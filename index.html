Huffman Compress

Lossless compression in C++, with the data structures built by hand.

A file compressor built on a custom Huffman coding algorithm. A min-heap and binary-tree structures build the frequency table and the optimal prefix codes. Text files come out 40–60% smaller, and decompression restores every byte exactly.
